Code lookup

Look up what a numeric NZLUM code meant in a given version. Pick a version, or go directly to https://nzlum.landcareresearch.co.nz/landuse/code/nzlum<version>/<code>.

Codes are not stable across versions: some have been reassigned to different concepts. Data records should therefore carry the NZLUM version alongside the code.
